# Module 2 — Python Hacks

This module is the senior engineer's utility belt. Nothing earth-shattering on its own. Together, the hacks here will save you hours per week and pull the elegance of your code up a level.

Pages:

1. **[Iteration and lookup hacks](01-iteration-hacks.md)** — `bisect`, `heapq`, walrus, generator tricks, dispatch tables.
2. **[Collections you forgot you had](02-collections.md)** — `Counter`, `deque`, `ChainMap`, `defaultdict`, `OrderedDict` (still useful), `SimpleNamespace`.
3. **[Performance and profiling](03-performance.md)** — `cProfile`, `py-spy`, `scalene`, `tracemalloc`, when to optimise, when to leave it.
4. **[Plugin patterns and registries](04-plugins.md)** — `__init_subclass__`, `entry_points`, the registry pattern, monkey-patching ethics.

Read in order if you're going for completeness, or jump to whichever section solves the problem in front of you.
