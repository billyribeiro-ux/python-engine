# Module 6 — Statistics + probability for traders

This module is the statistics class your university didn't teach because it would have been heretical. Almost every assumption in introductory statistics — IID, normality, fixed parameters, well-defined population — is violated by financial data. Use the textbook tools naively and you get great-looking results that don't replicate.

This module covers:

1. **[Hypothesis testing and the p-hacking trap](01-hypothesis-testing.md)** — why the standard p-value framework is broken for backtests, and what to do instead.
2. **[The bootstrap, properly](02-bootstrap.md)** — non-parametric inference; the block bootstrap for time-series; what you get and what you don't.
3. **[Bayesian thinking for traders](03-bayesian.md)** — priors, posteriors, Monte Carlo, PyMC patterns that survive contact with markets.
4. **[Copulas and tail dependence](04-copulas.md)** — joint dependence beyond the correlation coefficient.
5. **[Extreme value theory](05-evt.md)** — fitting the tail you actually care about for risk.

Start with **[Hypothesis testing and the p-hacking trap](01-hypothesis-testing.md)**.
