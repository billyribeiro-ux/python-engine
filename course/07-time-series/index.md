# Module 7 — Time Series

Time series is the part of statistics where almost everything in finance happens. This module covers the tools you'll reach for week-in week-out: stationarity tests, ARIMA/GARCH for vol modelling, Kalman filters for state estimation, particle filters when the system is non-linear, wavelets for multi-scale structure, and change-point detection for regime breaks.

Pages:

1. **[Stationarity, ADF, KPSS, and friends](01-stationarity.md)** — what stationarity means and how to test for it.
2. **[ARIMA and the GARCH family](02-arima-garch.md)** — the workhorse models for returns and volatility.
3. **[Kalman filters from scratch](03-kalman.md)** — the optimal linear-Gaussian estimator, and the practical applications (pairs, regression coefficients).
4. **[Particle filters](04-particle.md)** — when the system is non-linear or non-Gaussian.
5. **[Wavelets and the Hilbert transform](05-wavelets.md)** — multi-scale and instantaneous-phase analysis.
6. **[Change-point detection](06-change-points.md)** — CUSUM, BOCPD, `ruptures`.

Start with **[Stationarity, ADF, KPSS, and friends](01-stationarity.md)**.
